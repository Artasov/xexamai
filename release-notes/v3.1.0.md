## Highlights

XEXAMAI 3.1 focuses on faster live transcription, multimodal interview assistance, a cleaner compact interface, and a more reliable desktop/release lifecycle.

### Realtime transcription

- Added OpenAI Realtime transcription with `gpt-live-transcribe`, automatic multilingual and code-switched speech recognition, secure short-lived client credentials, 24 kHz PCM streaming, corrected transcript reconciliation, and bounded reconnect buffering.
- Improved Google Gemini Live setup, binary WebSocket message decoding, interim/final transcript handling, retry behavior, and actionable connection errors.
- Added a stateful band-limited streaming resampler to reduce aliasing and improve recognition quality from common 48 kHz input devices.
- Reworked realtime provider switching and recording lifecycle so stale sessions cannot overwrite the currently selected provider or transcript.

### Multimodal questions

- Screenshots and clipboard images can now be attached directly to the Ask a question field, previewed as removable thumbnails, and sent together with text.
- The screenshot button now captures and attaches an image instead of running a separate screen-processing prompt.
- Attached images are included both with normal Send actions and questions built from recent recording-buffer segments.
- Removed the obsolete separate Screen Processing model, prompt, and timeout settings; image requests now use the selected LLM model and its normal prompt.

### Interface and window experience

- Refined the main composer, compact Send row, localized animated thinking status, API-key controls, profile cards, settings sections, hotkey fields, history, and status text.
- Made the welcome dialog and startup logo animations smoother, more compact, and consistently layered.
- Added thin theme-aware scrollbars and removed accidental full-container focus outlines while preserving deliberate control interactions.
- Improved initial window sizing, remembered dimensions, centered and work-area-safe placement, border resizing, cursor privacy behavior, and recovery from transient WebView2 startup failures.
- Moved feedback and update interactions into the header/modal flow and removed redundant interface text.

### Reliability, privacy, and security

- Added a startup fallback page and a deterministic Axios compatibility patch to prevent blank windows caused by frozen prototypes.
- Hardened provider-token and log redaction, bounded diagnostic excerpts, and improved fatal/startup error reporting.
- Updated the generated native IPC contract for the new realtime commands and removed obsolete screen-processing endpoints.
- Updated project licensing, notices, trademark guidance, privacy documentation, and platform behavior documentation.

### Distribution

- Release binaries, updater packages, and signatures are now stored only in the immutable S3 release path.
- GitHub Releases contain full notes and platform-specific S3 download links without duplicating large binary assets.
- Preserved signed Tauri updater manifests, atomic S3 channel promotion, retry-safe immutable publication, and draft-release recovery.

Existing user settings are migrated where necessary. The application keeps the selected provider keys in the operating-system credential store and never places long-lived OpenAI credentials in the renderer.
